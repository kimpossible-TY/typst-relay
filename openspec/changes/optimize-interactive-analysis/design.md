## Decisions

Static completion must prove a usable surface before bypassing execution. Resolved values, module interfaces, and array methods can use the existing completion renderer directly. Inferred dictionary keys are insufficient because runtime mutation can add fields. Preserve style-dependent elements, math symbol variants, dictionary methods, and postfix suggestions.

Known imported modules expose valid postfix snippets consistently, including when execution does not reach the target. Previously the type fallback returned only exported fields, while an observed runtime module also offered postfix snippets. The static path preserves export signatures and intentionally makes these valid snippets available without executing the document.

When static completion is insufficient, collect the first evaluation observation before trying a full document trace. Evaluation precedes layout in the existing trace, so an observed value retains the previous first-value selection, including dictionary mutations. If evaluation produces no observation, retain full tracing for contextual callbacks and active styles. This shortcut can still execute document code; it specifically avoids layout when evaluation already provides the required value.

Cancellation is cooperative at scheduling boundaries. The protocol queue allows cancellation for `textDocument/*`, `workspace/symbol`, and `workspace/willRenameFiles`; lifecycle, execute-command, and other extension requests ignore cancellation until explicitly supported. The response future captures its abort registration before dispatch, and terminal responses carry a request identity so cancelled IDs can be reused safely. A direct terminal response also releases any remaining scheduled future.

Queries routed through `ServerState::query_on` wait for one asynchronous admission permit. Cancellation or a newer input generation drops waiting snapshots. Input changes, saves, filesystem events, configuration updates, changed main-file selection, and effective pin-mode transitions invalidate the shared generation; this conservatively invalidates queries for other documents as well. Pin-mode transitions matter even when the primary entry is unchanged because they switch queries between primary-project and per-document worlds. Changing pin flags while another active pin preserves the same effective mode does not invalidate queries. Native CPU work runs on the blocking pool and retains its permit until completion even when its response is cancelled. A queued blocking task checks its generation and cancellation state again before executing. Already-running Typst work is not forcibly interrupted. Web builds retain synchronous execution after admission. Snapshot creation still occurs before admission, and custom package-analysis commands are outside this queue.

Document highlighting only walks the source syntax tree and converts positions. Opened documents use their synchronized in-memory source directly, alongside the existing syntax-only query paths, so a contextual completion holding the semantic permit does not delay highlighting. The worker stores the negotiated position encoding instead of a semantic context. The existing semantic request API remains a wrapper over the same source implementation and provides the previous disk-source fallback for documents absent from the open-file map. This avoids a second semantic lane and preserves loop traversal, highlight ranges, and closed-file behavior.

Completion prefetch runs blocking package-index I/O on the blocking pool. Each registry owns a permanent atomic prefetch claim made before scheduling; concurrent completions therefore do not fill the blocking pool with workers waiting for the same `OnceLock`. A cached index, including an empty error fallback, does not reserve prefetch. One claim per registry is consistent with the existing download result cache; direct downloads remain independent. Its JSON reader must buffer the HTTP response: an unbuffered `serde_json::from_reader` asks for individual bytes, and each `reqwest::blocking::Response` read crosses the async bridge. A sampled native-test shutdown spent minutes in this path at full CPU while waiting for the prefetch worker. Buffer at the parser boundary, preserving normalization and error handling, and verify bounded upstream reads without depending on the public registry or exact network timing. Workspace operation tests seed the existing test registry hook so unrelated filesystem assertions do not depend on live network prefetch.

Automatic cache maintenance uses a process-wide single-flight/coalescing coordinator. Requests pending before a sweep starts share that sweep; requests arriving during it reserve at most one follow-up sweep. `comemo::evict(1)` increments age and retains entries whose resulting age is at most one; hits reset age to zero. Thus a newly used entry survives one sweep and is removed on the next sweep if unused. Intervals are sweep intervals, not necessarily document revisions, and the policy is not an RSS limit. Manual clear-cache operations are outside the automatic coordinator. Source and VFS caches retain their existing project-specific policies and thresholds, with separate timing logs.

Accept the retention policy only after output equivalence and a repeated-edit comparison demonstrate acceptable memory and latency. Lower retention targets the observed accumulation without modifying dependency versions. The dependency still destroys expired objects under its cache write lock, so moving comemo destructors outside that lock remains an option if long stalls persist.

## Validation

Native validation reproduced a late compile-status notification after its editor receiver had closed. The previous `unwrap` propagated a worker panic to Rayon's process-wide abort path. Handle the closed channel consistently with diagnostic notifications and cover an actual compile handler invoked from a worker after editor shutdown. Workspace-change fixtures seed an empty package index because their behavior must be independent of the public registry; dedicated index regressions cover production parsing and prefetch ownership.

- Regression tests for static and dynamic completion surfaces, runtime trace counts, and equality between the first evaluation observation and the previous full trace's first value/styles.
- Cancellation tests for numeric/string IDs, unknown/repeated cancellation, reused IDs, exactly-one response, and stateful/lifecycle futures completing despite cancellation.
- Queue/revision tests proving stale queries do not run and running work retains the admission permit after cancellation.
- Unchanged highlight snapshots with direct-source/semantic-wrapper equality, including Korean/emoji input under UTF-8 and UTF-16. Independently verify UTF-16 ranges, hash-prefix inclusion, and nested-loop exclusion. Preserve the shared conversion helpers; their pre-existing UTF-8 scalar-column defect is outside this performance change.
- Deterministic eviction coordination and edit/revert shape geometry/position tests. This focused fixture does not establish full-document PDF equivalence or a memory bound; those require the release replay below.
- Query snapshots, sync-ls/project/runtime tests, formatting and strict crate clippy; feature matrix because native/web scheduling branches differ.
- Concurrent package-index claims produce exactly one owner, and a cached empty index schedules no prefetch. A large index fixture verifies metadata and chunked upstream reads; malformed JSON and I/O failures retain their error categories.
- Release replay on an unchanged saved document snapshot, original packages, at least 12 sequential edits when the memory guard permits. Compare semantic tokens, completion candidates, compile output, trace counts, memory, and latency. Preserve raw measurements privately; report limits honestly.
